# TV Show Management System

A Java web application for managing TV shows, featuring user authentication, session management, database integration and CRUD functionality.

## Features

- User registration and login
- Session-based authentication
- Add new TV shows
- View stored TV shows
- Update existing TV show information
- Delete TV shows
- Persistent database storage
- Web-based user interface

## Technologies Used

- Java
- Java Servlets
- JSP (JavaServer Pages)
- JDBC
- HSQLDB
- HTML
- Apache Tomcat
- Maven

## Application Structure

The application follows a structured approach with separate components for:

- **Model** – represents users and TV show data
- **DAO** – handles database access and SQL operations
- **Controller** – processes requests using Java Servlets
- **View** – provides the user interface using JSP pages

## Key Concepts Demonstrated

This project demonstrates:

- Server-side Java development
- User authentication and session management
- Relational database integration using JDBC
- CRUD operations
- Servlet request and response handling
- JSP-based web interfaces
- Separation of application logic into different layers
